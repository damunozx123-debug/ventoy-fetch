# Contributing and collaborating

Munoz Tech Labs is an emerging technology initiative. Contributions and genuine technical feedback are welcome when a project is publicly available.

## First steps
1. Check a project's README, open issues and licence before proposing changes.
2. For a bug, give a reproducible description, expected versus actual result, environment and logs with personal data removed.
3. Discuss large feature proposals in an issue before writing substantial code.
4. Keep changes small, documented and backed by relevant tests.
5. Disclose AI-assisted generation when it materially affects the code or review process; generated output still needs testing.

For private prototypes, request access by emailing damunozx123@gmail.com. Access, licensing and contribution rights must be discussed first.

No contributor is assumed to be an employee, contractor or partner merely by filing an issue. Do not submit passwords, customer records or unauthorised network scan data.
