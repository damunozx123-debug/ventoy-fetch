# Security reporting

For security issues that could expose data, compromise devices or affect others, **do not publish exploit details in a public issue**.

Contact: [damunozx123@gmail.com](mailto:damunozx123@gmail.com?subject=Private%20security%20report%20Munoz%20Tech%20Labs).

Include affected project/version, a minimal reproduction and realistic impact, avoiding real user data and unnecessary exploit payloads. Please provide a reasonable opportunity for assessment before disclosure.

A response timeline, paid bounty and production support are **not guaranteed**. Security tools and diagnostics are intended only for systems and networks where the operator has explicit authorisation.

Each repository should add project-specific reporting instructions if security handling differs.
