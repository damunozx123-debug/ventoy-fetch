# Optional portfolio website (GitHub Pages)

The responsive site is ready in `docs/index.html`, but GitHub Pages needs to be enabled by an account owner if it isn't already.

**How to publish:** Open [Ventoy Fetch → Settings → Pages](https://github.com/damunozx123-debug/ventoy-fetch/settings/pages). Under **Build and deployment**, select **Deploy from a branch** → **master** → **/docs** → **Save**.

After GitHub reports the site is deployed, the expected public address is `https://damunozx123-debug.github.io/ventoy-fetch/`. **Do not promote that URL as active until you've opened and checked it.**

The site has no analytics, trackers, cookie banner requirement or app downloads. Its portfolio project buttons open genuine repositories or send clear demo-request emails. Source ZIP links are labelled as *source*, not installable APKs.

**Mobile test checklist:** all three hero calls-to-action, email links, project category filters, source ZIP links, service pricing caveats and the portfolio contact details.

To show this same work directly on the [GitHub account profile](https://github.com/damunozx123-debug), also create the special public repository named `damunozx123-debug` and copy the `PROFILE_README.md` from this repository into that repository as `README.md`.
