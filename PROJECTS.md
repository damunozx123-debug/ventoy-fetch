## ✅ Public: open the source

### 📲 [Ventoy Fetch](https://github.com/damunozx123-debug/ventoy-fetch)

**Problem:** You're stuck with an Android phone and need operating-system / recovery ISOs for a Ventoy USB.

**What exists:** A Python/Termux download-and-verification workflow with checksum/signature handling, resumes and explicit unverified status where trustworthy upstream proofs are missing.

**My contribution:** User problem, product requirements, scenarios and AI-assisted code refinement.

**Try:** [Source, installation and usage](https://github.com/damunozx123-debug/ventoy-fetch) · [Issues](https://github.com/damunozx123-debug/ventoy-fetch/issues). No public APK or verified downloadable release is advertised.

**Next:** Device and endpoint validation; review licensing wording and screenshots.

### 🧮 [AI Cost Sensitivity Calculator](https://github.com/damunozx123-debug/ai-certainty-calculator)

**Problem:** Understand what a *hypothetical* monthly AI cost variance would mean.

**What exists:** A Streamlit source prototype using assumptions supplied by the user. It is not a billing integration, validated savings estimate or audit service.

**Try:** [Source + honest limitations](https://github.com/damunozx123-debug/ai-certainty-calculator).

**Next:** Input validation, clearer terminology and independent test data.
